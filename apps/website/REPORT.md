## Type pairing chosen

**Public Sans (body/UI) + Newsreader (display).** Both ship as true variable fonts on Fontsource, so
one latin-subset file per family covers every weight — the smallest self-hosted footprint — and
Newsreader gives the large editorial display contrast the brief wanted (the 76px hero spine) without
the Inter-at-four-weights tell.

## The two opinionated choices

1. **The bed-count calculator** (`/pricing`) — a slider + number input from 20–500 beds that shows
   the operator their real monthly/annual cost, GST, and which tier they land in. Keyboard-first,
   server-rendered defaults so it works with JS off, count-up disabled under reduced-motion. ~0.7 KB.
2. **The locked-up-rent calculator** (`/pricing`, dark section) — beds × avg rent × days-overdue ÷ 30
   → the rupees sitting in overdue right now. It turns the pitch ("pull your DSO to four days") into
   a number the operator computes on their own inputs. No template has this; it is the sharpest
   single argument on the site.

   Supporting non-template moves: the hero **breaks the grid** (screenshot bleeds off the right,
   left-aligned, no pill badge), and `/product` is anchored by a **dense capability table** rather
   than three equal cards.

## Deliberate deviations from the brief (with reasoning)

- **`<picture>` + sharp instead of Astro `<Image>`.** Astro's `<Image>` only optimises assets under
  `src/`, but the brief puts generated screenshots in `public/media/` (gitignored, rebuilt by the
  pipeline). Emitting AVIF+WebP+PNG from `shoot.mjs` with sharp and serving them via a `<picture>`
  component honours that location *and* gives the required AVIF-with-WebP-fallback plus explicit
  intrinsic dimensions. Same end result (sharp, AVIF/WebP, no CLS), better fit to the file layout.
- **Mockups copied into `mockups/`** (renamed `owner-app.html` / `resident-app.html`) so the
  screenshot pipeline is reproducible in CI and the owner's real name/brand could be scrubbed to the
  neutral demo values (**Arjun** / **Greenview**, the brief's own placeholder) at source rather than
  captioned around.
- **Demo POST via a Cloudflare Pages Function** (`functions/api/demo.ts`) rather than an Astro
  server route, so the site stays 100% static while the form still submits with JS disabled.
- **`--mut2` → `--mut` for small tertiary text** on sage backgrounds. `--mut2` (#6B7A74) clears 4.5:1
  on pure white but dips to 4.18 on `--sage`; `--mut` (#5A6A63) clears it everywhere. No token value
  was changed — only which existing token small text uses.
- **Analytics gated off** until `PUBLIC_PLAUSIBLE_SRC` is set, so there is no external request (and
  no console error) until the owner wires up a real Plausible host.
